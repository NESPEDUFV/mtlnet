## verdict

Use **LucasBraganca/ModeloLatexTeseUFV** (github.com/LucasBraganca/ModeloLatexTeseUFV, last push 2024-04-09, 10 stars) as the base, NOT the original TeseUFVLatex/ecothesis. It is a direct derivative of TeseUFVLatex already updated to the modern UFV BBT manual: margins are already exactly top/left 3 cm + bottom/right 2 cm, A4, 12 pt, page number top-right via fancyhdr, body wrapped in setspace `onehalfspacing` — i.e., 4 of the 6 mandatory 2025/2026 AcademicoPG rules are already satisfied out of the box, leaving only (a) a one-line font swap Palatino→Times/Arial and (b) stripping the now-forbidden front matter (which the AcademicoPG system generates). For per-chapter bibliographies (coletânea), copy the `chapterbib`+natbib wiring from the parent TeseUFVLatex (both are plain `report`-class, so the merge is trivial) or use biblatex `refsection=chapter`. This is the lowest-risk path for an August 2026 defense: it is 90% a deletion job plus two small preamble edits on a template someone already validated against the current BBT manual, and because the system now generates capa/ficha/resumo/abstract, a heavyweight abnTeX2 template buys nothing — the "template" that must survive is only: lists + sumário + body + per-chapter refs. (Equivalent fallback with identical effort: a ~40-line minimal `report`-class preamble from scratch; choose it only if you prefer zero inherited cruft.)

## tese_ufv_latex_assessment

**TeseUFVLatex (ViniciusBRodrigues) / CTAN "ecothesis"** — effectively ABANDONED. GitHub API: created 2017-03-12, last content commit 2019-07-01 ("Add files via upload"), last activity at all = README-only edits 2022-12-30; 5 stars, 0 forks, 0 open issues. CTAN ecothesis is v1.2, last announced 2018-06-14, maintainer Vinícius Barros Rodrigues (LPPL 1.3c; shipped in TeX Live/MiKTeX — the OpenMandriva "texlive-ecothesis" repo pushed 2026-07 is only distro packaging of the same 2018 version, not maintenance). Technical facts from main.tex (v1.3, July 2018): base is plain `\documentclass[12pt]{report}` — NOT abnTeX2; font is Palatino via `\usepackage[sc]{mathpazo}` with `\linespread{1.05}` (confirms the suspected Palatino conflict); margins `left=4cm,right=3cm,bottom=2.5cm,top=2.8cm` (an old print-era spec — violates the current 3/3/2/2); page numbers placed in the FOOTER (`\fancyfoot[L,RO]{\thepage}` plus `Capítulo N` footer) — violates the top-right rule; `\pagenumbering{arabic}` restarts at 1 after Resumo/Abstract — violates the continuous-count rule. Per-chapter bibliography: YES, its one genuinely valuable feature — `\usepackage[sectionbib]{chapterbib}` + natbib, with each `capitulos/capNN/` holding its own `referencias.bib` (structure fits the coletânea format). It ships a full pre-textual suite (preambulo/: capa, aprovacao, dedicatoria, epigrafe, agradecimentos, resumo, abstract) — ALL of which are now forbidden in the uploaded PDF, so most of what the template provides is dead weight under the 2025/2026 flow. Verdict on it: usable only as a donor of the chapterbib wiring; do not use as the base.

## compliance_gaps

Confirmed the official manual first-hand (ppg.ufv.br/wp-content/uploads/2025/08/Manual-de-entrega-de-dissertacoes-e-teses.pdf, PPG/2025, listed on the site as "Manual 04_2026"; §4, §6, §7, §8): uploaded PDF must contain ONLY (in order) lista de ilustrações/tabelas/siglas/símbolos + apresentação (all optional), sumário (obrigatório), corpo do texto; pre-textuais (dedicatória, agradecimentos — with mandatory CAPES/FAPEMIG/CNPq funding sentence auto-inserted —, epígrafe, resumo, abstract, palavras-chave) are filled IN the system; capa + ficha catalográfica system-generated, neither counted nor numbered; Fonte Arial ou Times New Roman 12; A4; margens sup+esq 3 cm, inf+dir 2 cm; espaçamento 1,5; numeração canto superior direito starting at the first body page, pre-textuais counted but unnumbered; the SYSTEM-emitted PDF is the numbering reference (divergences possible — verify via the "Emitir PDF/RASCUNHO" draft). GAPS of the RECOMMENDED base (LucasBraganca): (1) Font = Palatino (mathpazo) → EASY, replace 3 lines with `newtxtext/newtxmath` (Times-New-Roman-equivalent, pdfLaTeX) or XeLaTeX+fontspec `Arial`/`TeX Gyre Heros` if literal Arial is demanded; (2) forbidden front matter present (folha_de_rosto, aprovacao, dedicatoria, agradecimentos, epigrafe, resumo, abstract inputs) → EASY, comment out 7 `\input` lines; (3) page-count offset: numbering must start at (system pre-textual pages + own lists/sumário pages + 1), unknowable until the system draft exists → EASY but ITERATIVE: `\pagestyle{empty}` on lists/sumário + `\setcounter{page}{K}` at the introduction, tune K against the RASCUNHO PDF; (4) per-chapter bibliographies absent → MODERATE (half a day): port `\usepackage[sectionbib]{chapterbib}` + per-chapter `referencias.bib` + `\include`-per-chapter from TeseUFVLatex (chapterbib requires one \include per chapter and separate bibtex runs per .aux — fine since the repo already \includes chapters), or use biblatex `refsection=chapter` + `\printbibliography` per chapter if a single modern style across articles is acceptable; (5) `\linespread{1.5}` in preamble is slightly larger than true 1.5 spacing — replace with setspace `\onehalfspacing` globally (body already uses it) → TRIVIAL; (6) coletânea niceties: rename chapter headings (Introdução Geral / ARTIGO 1..N / Conclusão Geral) and optionally per-article language via babel `\selectlanguage` → EASY (manual/norms allow each article to keep its own formatting and language). For TeseUFVLatex as base the gaps are strictly worse: margins, footer page numbers, restart-at-1 pagination, Palatino, 1.05 spacing all wrong. For UFVMastersTemplate2021: font swap + stripping abnTeX2's capa/folha machinery + abntex2cite→per-chapter bib conversion (hardest of the three for coletânea).

## adaptation_checklist

Starting from LucasBraganca/ModeloLatexTeseUFV (clone or import to Overleaf): (1) FONT: delete `\usepackage[sc]{mathpazo}` and `\linespread{1.5}`; add `\usepackage{newtxtext,newtxmath}` (Times New Roman look, pdfLaTeX-safe). If the secretariat insists on literal Arial: switch to XeLaTeX/LuaLaTeX + `fontspec` + `\setmainfont{Arial}`. (2) SPACING: add `\usepackage{setspace}\onehalfspacing` after fonts (body's existing `\begin{onehalfspacing}` may stay; remove redundancy). (3) STRIP FRONT MATTER: comment out all seven `\input{preambulo/...}` lines (folha_de_rosto, aprovacao, dedicatoria, agradecimentos, epigrafe, resumo, abstract) — these are filled/generated in AcademicoPG and must NOT be in the uploaded PDF. Keep `dados.tex` only if other macros still reference it. (4) DOCUMENT ORDER: ensure the PDF opens with (optional) lista de ilustrações → lista de tabelas → lista de siglas → lista de símbolos → (optional) apresentação → sumário → corpo. The repo currently orders LoF→LoT→ToC — keep that order (lists BEFORE sumário, per manual §6); add siglas/símbolos lists (e.g., simple `description` pages or `nomencl`/`acronym`) only if used. (5) PAGE NUMBERS: lists/apresentação/sumário pages must show NO number → the repo already does `\thispagestyle{empty}` on them; verify every pre-body page is empty-styled. Numbering position is already top-right — do not touch fancyhdr. (6) COUNT OFFSET: immediately before `\include{capitulo1/introducao}` insert `\setcounter{page}{K}` where K = (number of system-generated pre-textual pages: dedicatória+agradecimentos+epígrafe+resumo+abstract as rendered by AcademicoPG) + (your lists+apresentação+sumário page count) + 1. K is verifiable ONLY against the system's "Emitir PDF para solicitação da ficha catalográfica" (RASCUNHO watermark) draft — budget one iteration loop; the system PDF's numbering is authoritative (manual §7/§9). Capa+ficha are neither counted nor numbered — ignore them in K. (7) COLETÂNEA STRUCTURE: chapters = Introdução Geral; one chapter per article (each may keep its own language/formatting; use `\selectlanguage{english}` inside English article chapters); Conclusão Geral. Rename chapter files/titles accordingly. (8) PER-CHAPTER BIBLIOGRAPHIES: add `\usepackage[sectionbib]{chapterbib}` (before natbib usage — copy the exact wiring and per-chapter `referencias.bib` layout from ViniciusBRodrigues/TeseUFVLatex `capitulos/capNN/`), keep one `\bibliography{referencias}` + `\bibliographystyle{...}` INSIDE each `\include`d chapter file; compile pdflatex → bibtex on each capituloN.aux → pdflatex ×2 (Overleaf handles this automatically). Alternative: biblatex `[refsection=chapter]` + `\printbibliography[heading=subbibliography]` per chapter if one citation style for all articles is acceptable. (9) MARGINS/PAPER: already compliant (`a4paper,left=3cm,top=3cm,right=2cm,bottom=2cm`) — verify with a ruler on the output once after the font swap (font changes can shift headheight; keep `\setlength{\headheight}{14.5pt}`). (10) PROCESS: fill dedicatória/agradecimentos (must contain the standard CAPES/Financiamento 001 + FAPEMIG + CNPq sentence — the system inserts it, don't fight it)/epígrafe/resumo/abstract/keywords directly in AcademicoPG using "colar sem formatação"; upload the PDF; emit RASCUNHO; fix K; request ficha catalográfica from BBT via https://www.bbt.ufv.br/ficha-catalografica-on-line/ (7-day SLA, inside the 3-month no-fine window); attach ficha; send for advisor signature ("Enviar"). (11) SANITY: cross-check against PPGCC's July-2024 pre-textual checklist (ppgcc.ufv.br/wp-content/uploads/2024/07/CHECK-LIST-…Dissertacao-e-Tese.pdf) and confirm with the PPGCC secretariat (ppgcc@ufv.br) that the coletânea per-article citation styles are acceptable. Total estimated effort: ~1 day of LaTeX work + one system-draft iteration.
