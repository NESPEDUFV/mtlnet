\section{What was measured, and on what unit}
\label{apx:cosine:setup}

At every training epoch, each task loss was back-propagated to the shared cross-attention trunk, and
the cosine of the angle between the two resulting gradient vectors was recorded, the quantity the
gradient-surgery literature uses to define task conflict~\cite{yu2020pcgrad}. The cosine is the
% [round9c, 2026-07-30] CITATION ADDED at the author's instruction (PENDENCIAS_RESOLVIDOS 2.22 (arquivado 2026-07-30) point 4: "we
% should cite some article/studie/document that show this apporach"). yu2020pcgrad is already in
% references.bib and is the source Chapter 2's gradient-conflict definition cites (GLOSSARY §4
% "gradient conflict" row also pins it: Def. 1, arXiv:2001.06782). VERIFIED THIS SESSION at the
% source: arXiv:2001.06782 PDF opened; p.1 "We define two gradients to be conflicting if they point
% away from one another, i.e., have a negative cosine similarity"; p.4 Definition 1 and the PCGrad
% procedure compute the cosine similarity between task gradients; p.9 (Fig. 4) records the
% percentage of iterations with positive/negative gradient cosine during training, i.e. the same
% per-iteration measurement this appendix records per epoch. Author list checked against the arXiv
% API record.
right quantity because it is scale-free: it reads how the two requested updates are aligned and
ignores how large they are, which differs between the tasks and drifts during training. A cosine of
$+1$ means the tasks ask for the same update, $-1$ for opposite ones, and $0$ that the requests are
orthogonal, each leaving the other's objective unchanged to first order.

The observations are 1,000 epoch-level cosines from four datasets: Istanbul, Alabama, Arizona, and
Florida contribute 250 each, one measurement per epoch on each of five folds. Every run is the
reported joint configuration under five-fold user-disjoint cross-validation over fifty epochs, at
one random initialization. Each run reproduces its dataset's banked seed-0 cell to four decimal
places on both tasks, which is what ties the
diagnostic to the model the chapter reports rather than to a nearby variant.
